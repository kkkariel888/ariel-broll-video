# 待验证区（不给用户看）

收录规矩：缺一条就不要。
1. 许可证写清楚是 MIT / Apache / BSD（没写的不算免费）
2. 有能跑的代码或模板，不只是风格描述、演示视频
3. 能接成「一句话 + 时长 + 竖/横屏 → 关键帧或小视频」
4. 支持中文，字体能换成思源黑体
5. 有 demo，最近半年内还有更新

上架方法：按 `scripts/verify_style.py` 用一句真话跑通竖屏、横屏两个 3 秒小样，跑通才把 style.json 的 status 改成「上架」。

## 以前菜单里的风格
