# 口播配动画 B-roll（Claude / Codex 通用）

**说话方式**：少说话，直接干活。不寒暄、不解释流程。能让用户点的就不让用户打字；真要问，一次只问一个问题。用中文、大白话。

本 skill 文件夹里有：
- `scripts/highlight_server.py`：标黄 + 选风格小助手（只用 Python 自带库）
- `scripts/lemo.py`：下载 / 更新 Lemo-Opuscar 风格库，列出能用的风格
- `scripts/render.py`：把画面页渲染成关键帧图或视频（Python 自带库 + 本机 Chrome + ffmpeg）
- `scripts/dna.py`：参考图量主色、量剪辑节奏、查 GitHub 许可证、存进「我的风格」
- `scripts/fonts.py`：下载风格说明里点名的开源字体
- `assets/highlighter.html`：仿 Word 的标黄页面，确认后接着选风格
- `references/style-dna.md`：参考图提炼风格的规矩；`references/open-source-review.md`：开源项目核验记录

## 第 0 步：开工前（每次都跑，很快）
先看一眼用户的文件夹：至少要有 1 个 `.srt` 和 1 个口播视频。缺了或有好几个，按文末「出错了怎么办」处理，**先别下载风格库**。
0. `python3 <本skill>/scripts/update_check.py`：查有没有新版本，有就自己更新（下次对话生效）。只在最后一行是 `STATUS=updated` 或 `outdated` 时跟用户说一句，其他情况不吭声。
1. `python3 <本skill>/scripts/lemo.py ensure`：第一次会把 Lemo-Opuscar 下载到 `~/lemo-opuscar`（约 30MB），以后只更新。
   **必须下载成功才能往下走。** 失败就把它打印的原因告诉用户（多半是网络连不上 GitHub），等用户说「重试」。没有保底风格，不要自己凑。
2. 检查 `git`、`ffmpeg`、Chrome（或 Edge）在不在。缺了就**直接帮用户装**（Mac：`brew install ffmpeg git`；能跑仓库根目录的 `install.sh` 就跑它），只有要用户本人点的（Mac 弹窗、输开机密码）才叫用户，不要假装做完。

## 第 1 步：读文件夹 + 审错别字
- 用户给的文件夹里有剪映导出的 `.srt` 和口播视频。用户也可能顺手给了：参考图、GitHub 风格链接、「用上次那个」。
- `ffprobe` 读宽、高、帧率、时长（有 rotation 90/270 就把宽高对调再判断）。宽小于高是竖屏 9:16，宽等于高是 1:1，宽大于高是横屏 16:9。**不要问画幅。**
- 只改错别字和听写错误，不改说法、不加标点、不动时间轴。原 SRT 不动，另存 `字幕_修正.srt`。对话里用小表告诉用户：时间 | 原来 | 改成。

## 第 2 步：侧边打开仿 Word 文档并标黄
1. 按时长定数量：视频秒数 ÷ 6 取整，最少 3 处、最多 15 处（30 秒 → 5 处，60 秒 → 10 处）。挑建议做 B-roll 的地方（有数字、有步骤、有对比、概念抽象、最想让观众记住的），原文一字不差写进 `建议标黄.json`（字符串数组）。
2. 后台启动小助手：`python3 <本skill>/scripts/highlight_server.py 字幕_修正.srt --suggest 建议标黄.json --out <用户的文件夹>`
3. 在侧边浏览器打开它打印的地址（见文末「在哪打开」）。对话里只说一句：
   > 右边我先标了 N 处，直接改就行。改好点「确认标黄」，下面点「文字多 / 动画多」，再看风格样图点一下。
4. **用户在改标黄的同时，你马上开始第 3 步**（挑风格、画样图），这样用户点完确认时样图已经好了。

## 第 3 步：挑风格并画样图（在用户标黄时后台做）

### 风格从哪来（按这个顺序）
1. **用户给了参考图** → 按 `references/style-dna.md` 提炼风格 DNA，写成一个新风格（当期草稿），排第 1 名。再按第 4 条从 Lemo 挑 2 个和它长相差别大的当第 2、3 名，给页面上的「换一个」用。
2. **用户给了 GitHub 风格链接** → `python3 scripts/dna.py license <链接>` 先查许可证：
   - 「可以用」/「分块看」：读它的风格说明（配色、字体、动效数值），只在用户这台电脑上用来给这期视频画画面；不把它的内容存进本 skill。
   - 「有限制」：只能读来做用户自己的片子，告诉用户限制是什么。
   - 「不能用」：直接告诉用户，换别的来源。
   - 仓库里不是一份风格说明，而是一整个风格库（很多风格卡 / 动画语法卡，没有单个 `STYLE.md`）→ 从库里挑 3 张最合适这期的卡当 3 个候选，`style_md` 指向那张卡的文件。候选起中性名字（比如「白板手绘」），不用库里的品牌、作品、角色名。
3. **用户说「用上次那个」** → 读 `~/.broll-video-maker/last.json`。
4. **都没给** → 从 Lemo-Opuscar 挑：`python3 scripts/lemo.py catalog --out <用户的文件夹>/风格目录.json`（已去掉需要 AI 生图的风格；用户自己的风格 `~/lemo-my-styles/` 也在里面）。
   读完整份字幕，判断这期在讲什么（讲原理 / 比数字 / 讲新闻 / 演示工具 / 讲结论各占多少）、语速快慢、整体气质，从目录里挑 **3 个**最合适的，第 1 名最稳，第 2、3 名和第 1 名长相差别要大。

### 画样图
- 每个候选，挑 3 句**不同类型**的标黄原话（比如一句带数字、一句讲原理、一句讲工具），按这个风格的 `STYLE.md` **为这句话专门画一张**。不是套模板：画面内容跟着这句话的意思走，长相（配色、材质、字体、动效、镜头语言）严格照 `STYLE.md`。
- 画法见下面「画面页怎么写」。样图出一张定格：`render.py <页面> --size <视频尺寸> --at <秒> --out 风格样图/<slug>_1.png`。`<秒>` 取页面 `KEYTIMES` 里「最满」那一秒，没写就取 `DUR × 0.7`。样图的画面页放 `风格样图/页面/<slug>/`（不要放进 `逐帧代码/` 或 `风格草稿/`）。
- 写 `<用户的文件夹>/风格排名.json`：
  ```json
  {"aspect":"9:16","size":"1080x1920","candidates":[
    {"slug":"dark-keynote","name":"暗色科技发布","source":"lemo","style_md":"~/lemo-opuscar/styles/dark-keynote/STYLE.md",
     "why":"一句话：为什么最适合这期","samples":["风格样图/dark-keynote_1.png","风格样图/dark-keynote_2.png","风格样图/dark-keynote_3.png"]},
    {"slug":"…","why":"跟上一个比：哪里不同", "…":"…"}
  ]}
  ```
  `source` 是 lemo / mine / dna / github。先写第 1 名（页面马上能看），画好一个加一个。

### 页面上用户只点
- **文字讲解多一点 / 纯动画多一点**。
- 看到第 1 名的 3 张样图：**就这个**、**换一个**（给后两个候选）、**用上次那个**（桌面版 Claude 和 Codex 能记住；网页版记不住）。
- 候选都看完还不满意，用户会在对话里说「再换」：再挑 2 个、画样图、追加进 `风格排名.json`。

## 第 4 步：读结果
- `标黄结果.json`：`confirmed` 为 true 才继续；`result` 每项是 `no`（B1…）、`text`、`startTime` / `endTime`（秒），时长直接用。
- `风格选择.json`：`slug`、`name`、`source`、`style_md`（风格说明的位置）、`mode`（text / anim）。
- 用户如果在对话里粘贴了「标黄结果（共 N 处）：…」，就用粘贴的内容；风格在对话里用能点的选项问。

## 第 5 步：逐帧图审稿
- 先通读选定风格的 `STYLE.md`（全部 11 节），需要的话 `lemo.py demo <slug>` 下载它的演示片源码，只用来参考写法，不照搬故事和画面。
- **每一处标黄单独写一个画面页** `逐帧代码/B3.html`：内容按这句话设计，长相照 `STYLE.md`；时长 = `endTime - startTime`；关键词在说到的那一刻出现；`mode` 是 anim 就少放字。
- 出关键帧：`render.py 逐帧代码/B3.html --size <视频尺寸> --keyframes --label "B3 · 00:41：原话" --out 逐帧图/B3`（开场 / 最满 / 定格 3 张）。
- **一张一张单独发**，绝不拼成大图；图下的标注不进成片。用户点名改哪张只改哪张。全部确认前不渲染视频。确认过的存进 `已确认逐帧图/`。

## 第 6 步：对齐语速并出片
- `render.py 逐帧代码/B3.html --size <视频尺寸> --fps <视频帧率> --out 成片/B3.mp4`（libx264 -crf 16）。先渲染 1 段给用户看。
- 让用户二选一：A. 只要动画片段 + 时间表，自己进剪映拼（原片零损失）；B. 直接嵌进原视频（libx264 -crf 16 或更低，音轨直接复制）。
- 画质只能保持或更高。交付前列出原片和成片的分辨率、帧率、码率。

## 第 7 步：交付
文件夹里有：`字幕_修正.srt`、`标黄逐字稿.docx`、`标黄结果.json`、`风格选择.json`、`风格样图/`、`逐帧代码/`、`已确认逐帧图/`、`成片/`。成片另存一份到用户桌面。

## 不要做的事
| 不要 | 为什么 / 改成 |
|---|---|
| 自己转写语音来编字幕 | 时间轴和原话会错。没有 SRT 就停，让用户从剪映导出。 |
| 改用户的原文件（SRT、视频、逐字稿） | 修正一律另存（`字幕_修正.srt`），原文件不动。 |
| 改口播的说法和数字 | 只改错别字。发现数字对不上（比如口播说「省一百五十多个小时」，按它自己的说法算不到），在错别字小表下面提一句，让用户决定。 |
| 替用户点「确认标黄」或替用户选风格 | 这两步只能用户点。用户不在就停下来等。 |
| 逐帧图没全部确认就渲染视频 | 返工成本最高的一步，必须等全部确认。 |
| 把几张逐帧图拼成一张大图发 | 一张一张单独发，用户才能点名改哪张。 |
| 画真实品牌的界面、logo、角色，或用品牌/作品名给风格起名 | 版权风险。风格名起中性的，比如「暗色发布会」。 |
| 把 Lemo 或 GitHub 风格的内容存进本 skill、发给别人 | 只在用户电脑上现读现用（见「版权和致谢」）。 |
| 风格库下载失败时自己凑一个保底风格 | 没有保底风格。告诉用户原因，等用户说「重试」。 |
| 降低画质（crf 大于 16、降分辨率或帧率） | 画质只能保持或更高。 |
| 软件没装好却说装好了 | 要用户本人操作的（Mac 弹窗、输开机密码）就直说。 |

## 出错了怎么办（遇到就照做，不要自己绕过去）
| 情况 | 怎么办 |
|---|---|
| 文件夹里没有 `.srt` | 停。告诉用户：剪映里「文本 → 智能字幕 → 识别字幕」，再「导出」只勾「字幕导出」、格式选 SRT，放进这个文件夹后回「好了」。**不要自己转写语音来编字幕。** |
| 没有口播视频 | 停。请用户把口播视频放进文件夹（画幅、帧率、时长都要从视频里读）。 |
| 有好几个 `.srt` 或视频 | 用表列出文件名和时长，让用户点一个。不要猜。 |
| SRT 最后一句的结束时间和视频时长差 2 秒以上 | 把两个数告诉用户，问是不是同一期。用户说是再往下走。 |
| `ffprobe` 读不出 | 告诉用户视频可能坏了或格式不支持，请重新从剪映导出。 |
| 标黄小助手起不来 | 端口被占时它会自动换端口，以它打印的地址为准。还起不来就把报错告诉用户，改用对话里粘贴标黄（第 4 步最后一条）。 |
| 侧边浏览器打不开或被别的页面占着 | 把地址发给用户自己点开。 |
| 电脑上没有中文字体 | `python3 scripts/fonts.py copy "Noto Sans SC" 逐帧代码/`（约 17MB）。下载失败就告诉用户原因，等用户说「重试」；不要随便换成别的字体。 |
| `render.py` 找不到 Chrome | 请用户装 Chrome，或者设好环境变量 `CHROME` 指向浏览器。 |
| 渲染出来空白、字出框、元素叠在一起 | 改页面后重新渲染，同一张最多改 3 次。还不行，把这张图和问题告诉用户。 |
| `dna.py license` 失败，或 3 分钟没结果 | 告诉用户，让用户点「重试」或「改用 Lemo 风格」。 |
| `lemo.py catalog` 结果是空的 | 重跑一次 `lemo.py ensure`，还是空的就把输出告诉用户，等用户说「重试」。 |
| 用户一直没点「确认标黄」 | 样图画完就停下来等。**不要替用户确认，也不要先画逐帧图。** |

## 画面页怎么写
- 一个 HTML 文件，满足 Lemo 的页面约定：`window.DUR = 秒数`；`window.render = t => {…}`（同一个 t 永远画出同一张，不用定时器、不用 CSS 过渡）；字体图片加载完设 `window.READY = true`；可选 `window.KEYTIMES = [开场, 最满, 定格]`。
- 画布尺寸 = 视频尺寸（竖屏 1080×1920）。Canvas 2D 或 DOM 都行。可以 `import` Lemo 的工具：`/core/lib.js`（缓动、弹簧、噪声等，MIT），`render.py` 会从 `~/lemo-opuscar` 提供。
- 字体：照 `STYLE.md` 点名的开源字体，`python3 scripts/fonts.py copy "字体名" 逐帧代码/` 下载到页面旁边，用 `new FontFace` 加载。中文没点名就用思源黑体 / 思源宋体（Mac 一般没装，用 `fonts.py copy "Noto Sans SC"` 或 `"Noto Serif SC"` 下载）。
- 画面里不画字幕条（字幕在剪映里统一加）；竖屏底部 1/5 不放关键内容，给字幕留位置。
- 不画任何真实品牌的界面、logo、角色；风格说明里写了「不要用它们的名字、界面、字体」的照做。
- 多个画面共用的零件（纸张、笔触、面板）抽成一个 `.js` 放在 `逐帧代码/` 里，整期一致。

## 参考图 → 风格 DNA（第 3 步第 1 条）
按 `references/style-dna.md`：程序量颜色（`dna.py colors 图`，是视频再加 `dna.py cuts 视频`），AI 看图判断其余；只记感觉不抄图。写成 Lemo 同样格式的风格（`style.json` + `STYLE.md`，可参考 `~/lemo-opuscar/styles/_template/STYLE.md` 的小节）放在 `<用户的文件夹>/风格草稿/<slug>/`。出样图时再出一张 `render.py --compare 参考图 样图 --out 对比.png` 给用户看有没有太像；用户觉得太像就说「再离远一点」，把配色或节奏往外推一档。用户满意：`dna.py save 风格草稿/<slug>` 存进 `~/lemo-my-styles/`，以后和 Lemo 风格一起参与挑选。

## 在哪打开标黄页面
| 环境 | 做法 |
|---|---|
| Codex 桌面 app | in-app browser（侧边浏览器）打开地址 |
| Claude 桌面 app | 内置浏览器（侧边面板）打开地址 |
| Claude Code / Codex CLI | 把地址发给用户点开 |
| Claude 网页版（碰不到用户电脑） | 把 `assets/highlighter.html` 里的 `__DATA__` 换成页面数据，发布成右侧可交互页面并开启页面数据存储（db），确认后读 `transcript/current`；风格在对话里用能点的选项问 |

页面数据格式：`{"title":名称,"blocks":[{"type":"p","text":原文,"hl":[[起,止]],"sug":[[起,止]],"cues":[[字起,字止,秒起,秒止]],"time":"00:12"}]}`。环境变量 `CHROME` 可指定浏览器路径。
