# 暖纸拼贴 — Style Prompt（测试用的「我的风格」，原创）

## 1. Essence
撕边牛皮纸 + 手写数字 + 一个重点色。像笔记本里剪贴的一页：每屏只说一件事，数字最大。

## 2. Materials & rendering
- 底：暖米色纸 #EFE6D2，细颗粒噪点；色块是撕边纸片（边缘不规则、带 2px 浅色毛边），轻微投影。
- 线条：深褐 #3B2F2A，圆头，粗 6px。

## 3. Colour logic
底 #EFE6D2，墨 #3B2F2A，纸片 #D9C9A8，重点只用番茄红 #D9472B（标出这屏最重要的那个数或词）。不用渐变。

## 4. Type
中文 Noto Serif SC 700（标题 96–120px），数字 Jost 600（160px 以上），说明 Noto Sans SC 400 36px。左对齐，左边距 110px。

## 8. Pitfalls
- 不要满屏贴纸片，最多 3 块。
- 竖屏底部 1/5 不放内容（留字幕位）。
