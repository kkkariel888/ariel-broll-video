# ariel-skills

Ariel 开源的 AI skill 合集。**订阅一次，以后作者每次更新，你这边自动变成最新版。**

## 安装（只做一次）

**Claude 桌面 app / 网页版**：设置 → Customize → Plugins → 从 GitHub 添加插件市场，输入 `kkkariel888/ariel-skills`，再安装需要的插件。

**Claude Code**：
```
/plugin marketplace add kkkariel888/ariel-skills
/plugin install broll-video-maker@ariel-skills
```

**Codex**：
```
codex plugin marketplace add kkkariel888/ariel-skills
codex plugin add broll-video-maker@ariel-skills
```

## ⚠️ 打开自动更新（只做一次）
第三方插件市场默认不自动更新。Claude Code 里运行 `/plugin` → Marketplaces → 选中 `ariel-skills` → Enable auto-update。之后每次开新对话都会自动拉最新版。

## 插件列表
| 插件 | 做什么 |
|---|---|
| broll-video-maker | 给口播视频配代码动画 B-roll：审错别字、仿 Word 标黄、从 Lemo 风格库 / 参考图 / GitHub 链接挑风格、每个画面按风格现画、逐帧审稿、对齐语速、出片（风格库首次使用时自动下载：Lemo-Opuscar by Lemomo） |
